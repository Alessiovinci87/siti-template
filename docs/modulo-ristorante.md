# Modulo raccolta dati: Ristorante / Bar

Questi sono i campi da mettere nel modulo che compila il cliente (Tally, Google Form o un modulo nostro).
Il cliente scrive **appunti grezzi**: i testi finali li scriviamo noi con l'AI (vedi `prompt-testi.md`).

Regola d'oro: **le 24 ore partono quando abbiamo tutto il materiale**, foto comprese.

## 1. L'attività

| Campo | Obbligatorio | Note per il cliente |
|---|---|---|
| Nome dell'attività | Sì | Esattamente come deve apparire sul sito |
| Tipo di locale | Sì | Trattoria, pizzeria, ristorante di pesce, bar, agriturismo... |
| Tipo di cucina | No | Es. cucina sarda, pesce, pizza napoletana |
| Anno di apertura | No | Se vuoi che compaia "Dal 1998" |
| Raccontaci il locale | Sì | Anche solo appunti: chi siete, la storia, cosa vi rende diversi, i prodotti che usate |
| Servizi | No | Spunte: tavoli all'aperto, asporto, consegna, opzioni vegetariane/vegane, senza glutine, menu bambini, accessibile in sedia a rotelle, animali ammessi, parcheggio |

## 2. Contatti

| Campo | Obbligatorio | Note |
|---|---|---|
| Telefono | Sì | |
| Numero WhatsApp | Consigliato | Diventa il pulsante "Prenota su WhatsApp" |
| Email | No | |
| Indirizzo completo | Sì | Via e numero, CAP, città, provincia |
| Link Google Maps | No | Se avete la scheda Google, incollate il link |
| Come arrivare | No | Es. parcheggio vicino, ingresso dal vicolo |
| Instagram, Facebook, Tripadvisor, TheFork | No | Link ai profili |

## 3. Orari

Per ogni giorno: chiuso, oppure una o due fasce (pranzo e cena). Più un campo note (ferie, chiusure stagionali).

## 4. Menu

Il modo più rapido per il cliente: **caricare una foto o un PDF del menu attuale**. Lo trascriviamo noi.
In alternativa: per ogni categoria, nome del piatto, breve descrizione, prezzo.
Chiedere anche: coperto, e se ci sono piatti vegetariani, vegani, senza glutine.

## 5. Foto (obbligatorie, si parte solo quando ci sono)

Testo da mostrare nel modulo: *"Foto orizzontali, con buona luce, senza persone in primo piano (tranne la foto del team). Va benissimo il telefono."*

| Foto | Quante | Note |
|---|---|---|
| Foto principale | 1 | Esterno del locale o sala più bella, **orizzontale**, va in alto a tutto schermo |
| Sala / ambienti | 2–4 | Sala, dehors, bancone, vista |
| Piatti | 4–8 | I piatti più rappresentativi, dall'alto o di tre quarti |
| Team o titolare | 1 (facoltativa) | Per la sezione "Chi siamo" |
| Logo | 1 (facoltativo) | PNG con sfondo trasparente o SVG, se esiste |

Spunta obbligatoria: *"Dichiaro che le foto sono mie o che ho il diritto di usarle, e autorizzo l'uso delle foto presenti sui miei canali (sito, social, scheda Google)."*

## 6. Dati legali (per il piede del sito)

| Campo | Obbligatorio |
|---|---|
| Ragione sociale | Sì |
| Partita IVA | Sì |
| Sede legale | No, se uguale all'indirizzo del locale |
| Email per la privacy | No, se uguale all'email principale |

## 7. Stile

Scelta tra 3 stili, con un'anteprima per ognuno:

- **Terra**: caldo e tradizionale, verde oliva. Per trattorie, agriturismi, cucina di terra.
- **Mare**: fresco e luminoso, blu e verde acqua. Per pesce, chioschi, bar sulla spiaggia.
- **Notte**: scuro ed elegante, bordeaux e oro. Per wine bar, cocktail bar, cene raffinate.

## 8. Dominio

"Hai già un dominio (es. trattoriarossi.it)?" Sì, quale / No, sceglietelo voi.
